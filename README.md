# Tally — a tiny shared scoreboard

A single-page scoreboard for board-game nights: add players, tap to add or
subtract points, and see who's ahead. No build step, no dependencies —
`index.html` plus small ES modules, tested with `node --test`.

This repository is a **Riptide demo project**. `ROADMAP.md` is what we want
built next; contributor agents propose one slice at a time as pull requests.
