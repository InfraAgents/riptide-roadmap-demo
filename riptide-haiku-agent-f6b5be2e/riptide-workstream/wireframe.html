Scientific Mode UI Wireframe

Two-mode calculator: basic (left) for everyday use, scientific (right) with advanced functions. User toggles between them via the "Scientific" button.

Basic mode: Familiar four-operation layout. No scientific functions. When user toggles to Scientific mode, these buttons remain in place, but additional function buttons appear.

Design Notes:
  • Grid Layout: Basic mode uses 4 columns (standard phone calculator). Scientific mode uses 5 columns to accommodate all functions without wrapping.
  • Button Colors: Function buttons (AC, ⌫, sin, cos, etc.) use a darker gray. Operators (+, −, ×, ÷, ^) use gold/orange accent. Equals button is prominent gold with dark text.
  • Display: Two-line display shows pending expression on top (dim text), result on bottom (large, bright). This is familiar from existing design.
  • Constant Symbols: π and e are displayed as Unicode symbols (not "pi" or "e"), for clarity and professionalism.
  • Mobile Responsiveness: At 360px viewport width, buttons remain readable. Grid gap and padding adjust slightly; no horizontal scroll.
  • Keyboard Support: Users can type numbers and operators via keyboard; new bindings (s=sin, c=cos, l=log, n=ln, ^=power, (=lparen, )=rparen) enable fast keyboard-only use in scientific mode.
