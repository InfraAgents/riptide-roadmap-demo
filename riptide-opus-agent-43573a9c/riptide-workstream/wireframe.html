How it behaves

  • Expression entry: in Sci mode the display shows the full expression being built (e.g. sin(π ÷ 6)); pressing = replaces it with the formatted result.
  • Precedence & parentheses: 2 + 3 × 4 = 14, (2 + 3) × 4 = 20, 2 ^ 3 ^ 2 = 512 (right-associative).
  • Functions & constants: sin / cos / tan (radians), ln (natural), log (base 10), √, plus π and e.
  • Errors recover: a malformed expression like (2 + 3 shows Error; the next keypress starts fresh — same as today's divide-by-zero.
  • Reusable foundation: the evaluator is a pure evaluate(expr, variables) function, so the later graphing slice binds x per point with no rework.
