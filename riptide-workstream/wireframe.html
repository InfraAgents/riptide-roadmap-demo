Scientific mode — wireframe

The scientific keys stay hidden behind a Sci toggle so the basic keypad is never crowded. Opening it reveals functions, constants, parentheses, power/root, and a DEG/RAD switch. The expression line shows what will be evaluated.

Sci on — scientific panel + basic keypad together.

  • Sci toggle shows/hides the purple scientific panel; when off, the layout is byte-for-byte today's keypad (SC-004).
  • Expression line (top of the display) shows the full expression being built, e.g. 2 + sin(π / 6); the big number shows the last result on =.
  • DEG/RAD switches trig angle units; the badge reflects the current mode (FR-005).
  • Precedence & parentheses are handled by a new pure src/expression.js engine — the reusable foundation graphing will later consume.
  • Errors (unbalanced parens, √ of a negative, ÷ by zero) show the existing recoverable Error state — no crashes.
