Key Interactions & States

Precedence & Parentheses:
User enters 2 + 3 × 4 → Display shows 14 (not 20).
User enters (2 + 3) × 4 → Display shows 20.
Trigonometry:
In DEG mode: sin(90) → 1.
In RAD mode: sin(π/2) → 1.
Functions & Nesting:
User clicks sin button → sin( is inserted.
User can continue typing: sin(π/2) → 1.
Error Handling:
Mismatched parentheses or syntax errors show Error in display.
User can backspace or clear to recover.
Backward Compatibility:
Basic keypad works identically in both modes.
All existing tests pass without modification.

Responsive Behavior

Desktop: Basic and scientific keypads may appear side-by-side or in a toggle view.

Mobile: Keypads stack vertically. Scientific mode expands the calculator without horizontal scroll.

Dark/Light Theme: All UI respects the system color-scheme preference, just like the current calculator.

Entry Points for Users

Keyboard: Type numbers, operators, parentheses, and function names (e.g., sin(). Press Enter to evaluate.

Mouse/Touch: Click buttons to append characters, constants, or functions. Click = to evaluate.

Mixed: Start with buttons, continue with keyboard, or vice versa. The expression buffer accumulates all input until AC or =.
